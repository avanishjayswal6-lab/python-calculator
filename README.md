# Python Calculator Application

A command-line interface (CLI) calculator built using Python that handles fundamental arithmetic operations with built-in error handling for zero-division and invalid user input.

## Features
- Performs Addition, Subtraction, Multiplication, and Division
- Input validation to prevent crashes from non-numeric inputs
- Error handling for zero division (`x / 0`)
- Continuous execution loop until explicit exit

## How to Run
```bash
python calculator.py
